# RC Filter

RC low-pass core as a symbol (rc_core): on-chip R1 (2k) between VIN and VOUT. The capacitor is OFF-CHIP — the top schematic brings VOUT to ext_001 and a ground return to ext_002; solder the cap across them.

Open in Varquon CYGVEUM (File ▸ Examples). The core circuit is the `rc_core` symbol — use File ▸ Examples ▸ (this) ▸ Import Symbols to pull just `rc_core` into another project.
