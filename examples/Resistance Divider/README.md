# Resistance Divider

Two-resistor divider as a symbol (divider): VIN -> R1 (2k) -> VOUT -> R2 (10k) -> GND. The top schematic wires VIN/VOUT to external pins ext_000/ext_001 and GND to ground. Import the symbol to reuse it.

Open in Varquon CYGVEUM (File ▸ Examples). The core circuit is the `divider` symbol — use File ▸ Examples ▸ (this) ▸ Import Symbols to pull just `divider` into another project.
