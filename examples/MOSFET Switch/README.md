# MOSFET Switch

NMOS pass switch as a symbol (nmos_switch): IN=drain, CTRL=gate, OUT=source (body tied to source). Top schematic exposes IN/CTRL/OUT on ext_000/ext_001/ext_002.

Open in Varquon CYGVEUM (File ▸ Examples). The core circuit is the `nmos_switch` symbol — use File ▸ Examples ▸ (this) ▸ Import Symbols to pull just `nmos_switch` into another project.
