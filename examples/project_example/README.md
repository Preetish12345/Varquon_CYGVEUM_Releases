# project_example

A minimal Varquon CYGVEUM project showing the default folder layout, using
the built-in default chip and board.

- **Target IC:** `ic_tt_v1`  (built-in default)
- **Board:** `pcb_tt_v1`  (built-in default)

## Open it

In the app, **File ▸ Open Project...** and choose `del.cyv`.

Use this as a reference for what a fresh project looks like. For a complete,
explained circuit, open the [Inverter](../Inverter/) example instead.

See the [examples index](../README.md) and the
[main README](../../README.md) for more.
