# Common-Source Amplifier

Common-source amplifier as a symbol (cs_amp): NMOS with a 10k load to VDD, output at the drain. Top schematic wires IN/OUT to ext_000/ext_001 and attaches VDD and ground.

Open in Varquon CYGVEUM (File ▸ Examples). The core circuit is the `cs_amp` symbol — use File ▸ Examples ▸ (this) ▸ Import Symbols to pull just `cs_amp` into another project.
